# Matriz de aceptación — Formulario de talento Nexova

**Alcance:** entrega independiente [002-talent-form-nexova](../../../specs/002-talent-form-nexova/spec.md). Esta matriz no sustituye [la matriz de aceptación de la landing](./acceptance.md). **Actualizada:** 2026-10-23.

La implementación se contrastó estáticamente con la especificación. Las comprobaciones automatizables de sintaxis y compilación pasaron y los recursos respondieron por HTTP. No había Chromium ni `playwright`, `puppeteer` o `jsdom` disponibles en el proyecto; no se hicieron las pruebas interactivas, visuales, de red del navegador, lector de pantalla o JavaScript desactivado. Por ello, los criterios que exigen operación real se mantienen **Pendientes** y no se afirma aceptación completa ni conformidad WCAG certificada.

## Comprobaciones ejecutadas

- **2026-10-23, directorio `uis/website/`:** `node --check validation.js` y `node --check navigation.js` finalizaron correctamente; `npm run build` finalizó correctamente con Tailwind CSS v4.3.0.
- **Comprobación estática:** se cotejaron IDs, etiquetas, tipos, cantidad de radios/selects/textarea, literales de error y contenido de éxito con `spec.md`; también se revisaron enlace mailto, enlace LinkedIn, `<noscript>`, estado inicial deshabilitado/oculto y ausencia de tokens obvios de red o almacenamiento.
- **HTTP local, 2026-10-23:** el servidor local preexistente del puerto 8080 respondió 200 y contenido no vacío para `/application.html` (15.715 bytes), `/assets/styles.css` (18.830 bytes), `/validation.js` (8.317 bytes), `/assets/inter-latin-variable.woff2` (48.256 bytes) y `/index.html` (12.444 bytes). Se reutilizó el servidor; un intento de abrir otro en el mismo puerto reportó `EADDRINUSE` y terminó. HTTP acredita transporte/contenido, no interacción ni apariencia.
- **Limitación del entorno:** `command -v chromium`, `chromium-browser` y `google-chrome` no hallaron navegador; las resoluciones de módulos Node para `playwright`, `puppeteer` y `jsdom` reportaron no disponibles. No se instalaron dependencias para el formulario.

## Pendiente antes de declarar aceptación integral

Ejecutar en navegador los casos de CA-01–CA-07, CA-09 y CA-10; probar entrada, retorno, límites y corrección de errores con teclado; verificar visualmente móvil/escritorio/zoom, y observar Network y almacenamiento en envío válido. Registrar el navegador, tamaño, casos y resultados reales, así como las limitaciones de lector de pantalla. Actualizar esta matriz y las casillas 4.2–4.9 de `specs/002-talent-form-nexova/tasks.md` solo tras completar las comprobaciones correspondientes.
